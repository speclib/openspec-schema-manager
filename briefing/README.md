# ossm briefing package

Briefing for a one-shot POC of **ossm** (OpenSpec Schema Manager), to be fed to
the `1shotpoc` skill in Claude Code.

| File | Purpose |
|---|---|
| `KICKOFF.md` | The prompt to paste into Claude Code to start the run |
| `BRIEFING.md` | The full briefing: vision, scope, features, architecture, acceptance criteria |
| `CLAUDE.md` | Drop into the new repo root; standing instructions for Claude Code |
| `docs/decisions.md` | Decisions already made, with reasons. Do not relitigate these |
| `docs/screens.md` | Screen-by-screen TUI layout sketches and key bindings |
| `docs/open-questions.md` | Things the agent must verify before building on them |
| `fixtures/` | Illustrative registry and schema fixtures for tests and offline dev |

Suggested repo: `github.com/speclib/openspec-schema-manager`, binary `ossm`.
