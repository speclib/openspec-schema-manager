A README with recorded terminal demos and help text on every screen.

## Summary of Changes

A README that says what ossm is, what it does, how to run it, and what it cannot
do. The last of those is the part a proof of concept most needs: the
update-detection limit, the git requirement, the absent raw-file fallback and
the experimental schema commands are in the README, not left to be discovered.

Four recorded demos from VHS tapes checked into `demo/`, with a `setup.sh` that
builds a fixture registry, a real git repository to fetch from, three local
schemas and a demo project with two changes. Recording needs no network and
produces the same thing twice.

They are regenerated by hand rather than by the gate. Recording a terminal takes
minutes, and a gate that takes minutes stops being run.

`docs/keys.md` is generated from every screen's `Keys()`, the same method the
help overlay reads, and a test fails when the file on disk differs from what the
code would produce now. A key reference that drifts is worse than none, and the
only way it cannot drift is if nobody writes it by hand.
